AGUA REPARTO - VERSION CON SINCRONIZACION EN LA NUBE

Esta versión requiere configurar primero la base de datos con el archivo setup_supabase.sql.
No subas este archivo de instrucciones ni el SQL al sitio público de la aplicación.

IMPORTANTE:
- Cada persona tendrá una cuenta individual creada desde Supabase > Authentication > Users.
- No habilites el registro público de usuarios.
- El trigger de la base de datos incorpora automáticamente cada cuenta creada al espacio Agua Reparto.
- Los usuarios pueden crear y modificar clientes, cambiar precios y registrar/eliminar movimientos.
- No se concede permiso para eliminar clientes.
- Se requiere conexión a internet para consultar y guardar datos compartidos.
- El respaldo se descarga desde la pestaña Respaldo.

La URL del proyecto y la publishable key están configuradas en index.html. La publishable key está diseñada para usarse en el navegador; la seguridad real depende de las políticas RLS instaladas por el SQL. Nunca agregues una secret key ni service_role al archivo.
